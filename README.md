# MCPE Cheat Analyzer

Анализ IPA файла Minecraft PE 1.26.20 для поиска классов и методов.

## Как использовать

1. Загрузи IPA в релизы (тег v1.0)
2. Запусти workflow
3. Скачай артефакты с заголовками

## Результаты

После запуска workflow, в артефактах будет:
- `headers/` - папка с .h файлами классов
- `headers_raw.txt` - полный текстовый дамп
